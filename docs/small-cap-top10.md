# 小市值 Top10 日报 V1

本模块是独立、确定性的 A 股研究筛选器，不运行主 TA 分析图，不消耗 MiniMax/DeepSeek 选股额度，不下单。定时唤醒由 Codex 管理，唤醒任务本身不等于零模型使用；本地电脑与调度应用须可用。

## 每日交付

- 计划在每个中国交易日 **19:30 Asia/Shanghai** 启动；休市由沪深交易所日历确认后跳过，不重复发旧榜。
- 使用当日正式未复权收盘价及总市值、当日证券状态和采集时已可见的年度合并财报；面向下一实际开市日。
- 沪深主板人民币普通股；排除 ST、退市整理、已退市、上市不足 375 自然日，以及可靠证据确认的当日停牌/零成交。
- 总市值 10–100 亿元、收盘价不超过 50 元、年度归母净利润为正、营业收入超过 1 亿元；最新年度期末距行情日不超过 550 自然日。
- 只按总市值、代码升序取最多 10 只。少于 10 不凑数；可能改变前十边界的未知数据会阻止正式榜单发布。
- 一、四月只供研究观察，不新开股票仓位。强弱市定义、真实持仓、周二自动交易、日内补仓/止损均未实现，不能将名单当作买入指令。

## 阅读报告

先看 **状态与行情日期**，再看 **下一交易日、避险窗口和新仓状态**。SUCCESS 表示筛选完整，不表示看涨；INSUFFICIENT 表示完整筛选后不足十只；BLOCKED/ERROR 表示数据尚不能支持正式榜单。

每只候选用短条目展示名称、代码、行业、市值、收盘、财报利润/营收及数据证据。没有窄列长表。新增、移出、名次变化仅表示候选集合变化，不是调仓或卖出指令。次日开盘前仍需核对新公告和临时停牌。

## 使用

在项目根目录中，模块自行读取现有 `.env`，不会显示令牌：

```bash
.venv/bin/python -m tradingagents.strategies.small_cap run --no-notify
.venv/bin/python -m tradingagents.strategies.small_cap run --notify
```

默认不发送，只有显式 `--notify` 才发送。配置优先级为 `FEISHU_SMALL_CAP_WEBHOOK`，否则 `FEISHU_SMALL_CAP_USER_OPEN_ID` / 现有 `FEISHU_USER_OPEN_ID` 配合 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`；不借用大盘风险频道的 Webhook。带签名 Webhook 暂不支持，配置签名 secret 会明确拒发。

运行目录默认 `strategy_data/small_cap/`，不进入 Git：

- `snapshots/<行情日>/<内容哈希>.json`：封存原始响应和采集时点，无令牌。
- `reports/<行情日>/<运行ID>/result.json`：结构化结果及逐股排除原因。
- 同目录 `report.md`：确定性生成的手机阅读报告。
- `state.sqlite3`：归档索引和独立发送回执；报告生成并不等于发送成功。

重复成功运行会复用已封存结果；对失败的普通重试最多自动采集三次。需要额外重采时使用 `--refresh`，会生成新快照，不能修改旧报告。相同规则、日期、快照和收件人的刷新不会重复发送。新快照会产生新的通知身份，应仅在明确需要更正版时使用。

明确失败可重试原发送身份；结果不明（超时、发送后进程中断等）标记 `unknown`，禁止自动重发，需要先人工核对飞书。发送前重新检查下一交易日零点截止，不能补发过期候选冒充新榜。

```bash
.venv/bin/python -m tradingagents.strategies.small_cap preflight
.venv/bin/python -m tradingagents.strategies.small_cap replay \
  --snapshot /完整路径/内容哈希.json --output-dir /新的回放输出目录
.venv/bin/python -m unittest discover -s tests
```

`preflight` 会真实只读采集，不归档、不发送；回放完全离线，验证快照内容哈希，不能更改原始信息截止时点。历史重取数据不能冒充历史决策；本模块只从部署日起积累可审计的前向数据，不声称历史回测收益。

## 运行约束

Tushare API 需要交易日历、证券列表、`bak_basic`、`daily`、`daily_basic`、`stock_st`、`suspend_d`、`income_vip` 能力。已有积分档位不代表接口永久可用：每次采集验证返回码、日期、分页和覆盖；缺权限、限流或晚到时不自动换源、不回退旧日线。涨跌停接口 `stk_limit` 为附加风险标记，可缺失但会保留警告。

财报库可能含旧 IPO 预留标识，不等于可交易股票。若某深市代码只出现在财报、没有任何已捕获的证券/行情/状态正向身份，可额外下载深交所官方完整 A 股名录作身份核验。必须验证结构、唯一代码、上市日期以及对 Tushare 全部深市已上市人民币证券的覆盖（包括 ST/停牌）；仅在两份封存名录均支持、且无正向矛盾时，才能排除“当前已验证股票域之外的财报标识”。该结论只适用于采集时当前身份，不推断其从未上市或历史身份。官方名录不完整、过期、网络失败或出现矛盾时仍为 UNKNOWN，不能按空价格或网页搜索结果排除。沪市尚未接入相应官方核验，遇到未解决标识继续阻断。行情、市值、财务筛选数据仍全部来自 Tushare。

财报采集显式查询合并/调整/调整前版本，按互不重叠的公告日期区间分割；满单日仍达行数上限会拒绝发布，不能通过放行重复 offset 页来掩盖漏数。采集有 300 秒预算及有限传输重试；可从脱敏日志定位具体接口。

所有筛选参数和版本集中在 `tradingagents/strategies/small_cap/config.py`；更改筛选含义须升级规则版本，不按收益回溯调参。年度财报与自然日、总市值及公告日次日可用等属于工程口径，不声称精确复刻视频作者未公开的代码。
