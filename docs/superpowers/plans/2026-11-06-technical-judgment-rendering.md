**Goal:** Let the opt-in compact market analyst request bounded judgments, not a document plus two duplicate machine contracts.

- Review incomplete/new-stock data, T-1/intraday labels, cross-role handoff consumers, repeated schema injection via free text, and hidden retry multiplication.
